# 手动验收清单

编译、单元测试、进程启动和真实桌面操作分别记录，不能互相替代。SIP 开启前后的结果分别记录。

| 检查 | 预期 |
|---|---|
| 首次启动 | 显示菜单栏和说明，默认暂停，不调整现有窗口 |
| 未授权 | 启用失败，给出辅助功能设置入口 |
| yabai/skhd 在运行 | 拒绝启用，不修改它们的配置 |
| 快捷键被占用 | 明确失败并撤销已注册快捷键 |
| A S D F G H J K L | 普通桌面跨屏统一编号；不存在编号保持当前桌面 |
| Shift+A S D F G H J K L | 只移动当前窗口，确认归属；保持当前桌面 |
| Option+Return | 铺满当前桌面可用区域，再按恢复；不新建 Space、不改变原分区 |
| T | 新窗口显式加入平铺；再次切回浮动恢复本次应用运行中记住的平铺前尺寸 |
| 首次窗口基线 | 本登录会话首次建立基线时，已有窗口沿用平铺，包括其他 Space 和最小化中的窗口；恢复可见后仍为平铺成员 |
| 新窗口默认浮动 | 基线建立后新建窗口保持应用原始位置与尺寸，不重排已有平铺窗口 |
| 浮动归属持久化 | 暂停 / 恢复、重启 Yabaibye 后新窗口和手动浮动窗口仍浮动；重新登录或重启系统后重建基线 |
| [ / ] | 以焦点窗口确定当前屏幕，无焦点窗口时回退 `NSScreen.main`；屏幕内前后切换，Space 边界不循环、不跨屏 |
| Shift+[ / ] | 双屏时无论哪块为当前，都切换另一块的相邻 Space；通过 Mission Control 定点选择，完成后恢复原窗口焦点；单屏时报错 |
| 另一屏幕路由 | 显示器列表顺序改变仍以当前 UUID 定位；三屏以上选列表下一块，末尾回到第一块；无法识别当前屏幕时报错，不猜目标 |
| 四方向交换 | 与同 Space 中对应方向的平铺窗口交换 |
| 留白设置 | 外边缘与内部间距独立调整，范围 0–100 pt，预览与保存值一致 |
| 留白持久化 | 新启动恢复设置，修改不改变手动分区树 |
| 前台保护 | 普通后台遮挡可尝试 Raise；不越过系统浮层、不激活应用 |
| 自检完成 | 不自动弹结果窗口，菜单可主动查看 |
| 三窗口默认布局 | 三个平铺成员为 A 左上、B 左下、C 右侧满高；两列等宽，左侧上下等高，浮动窗口不占格子 |
| 四窗口默认布局 | 四个平铺成员在超宽屏仍保持 2×2 田字；新浮动窗口按 T 加入后才参与重排 |
| 拖到中心 | 整窗蒙版，松手交换两窗口位置 |
| 拖到四边 | 对应半窗蒙版，松手分割；同轴兄弟等分 |
| 三窗口示例 | 默认左侧 A/B、右侧 C；A 拖到 B 下方成为左侧 B/A、右侧 C；再拖 A 到 C 右侧成为手动 B/C/A 等宽三列 |
| 内容选择/窗口缩放 | 不显示分割蒙版，不改分区树 |
| Escape/无效落点 | 取消分割，松手恢复原分区 |
| 暂停/练习关闭 | 蒙版与观察定时器清理，恢复管理状态 |
| 关闭/最小化/隐藏平铺窗口 | 更新可见平铺布局；最小化或隐藏后恢复仍保留平铺归属，不包含对话框或全屏窗口 |
| 撤销权限/断开屏幕 | 停止或报错，不崩溃、不伪报成功 |
| 操作中暂停/退出 | 取消任务，释放快捷键注册 |
| 自检 | 测试窗口自动关闭，恢复两块屏幕原先桌面 |
| SIP 开启后 | csrutil 显示 enabled，再重复以上原生 Space 检查 |

自动测试不覆盖真实桌面/权限/系统动画；CI 无图形会话时只构建及运行核心测试。

| 新增验收 | 预期 |
|---|---|
| 快捷键自定义 | 按键/修饰键独立修改，保存即时生效，重启保持 |
| 重复组合与占用 | 清楚报错，不保存无效配置；注册失败恢复旧键位 |
| 自动布局升级 | 恢复旧版保存的自动三列布局，即使窗口成员未变，刷新后也变为左侧 A/B、右侧 C |
| 自定义布局重启 | 手动形成左侧 B/A、右侧 C，重启后仍保持；再拖 A 到 C 右侧成为 B/C/A 等宽三列，再次重启仍保持手动三列 |
| 多 Space 与测试隔离 | 各显示器/Space 保存各自树；练习、自检不覆盖真实布局 |
